[6:43 PM, 10/19/2026] Instrucciones generales:
 Vamos a elegir trabajar con la Plataforma A la cual esta divida en 3 modulos;
 PLATAFORMA A: Aplicación de Escritorio (Java Swing + MySQL/SQL) 
 
 • Módulo 1  DANIEL (Seguridad): Interfaz gráfica de Login. Uso de JPasswordField. Las credenciales deben validarse leyendo la Base de Datos. 
 • Módulo 2  Rodrigo (Admisión): Formulario con JTextField y JComboBox (urgencias). Debe incluir Protección Estricta (try-catch) para evitar colapsos por errores de tipeo. Los datos deben ensamblarse en un Objeto aplicando Herencia y Polimorfismo. 
 • Módulo 3 JEREMY (Persistencia JDBC): Los registros aprobados deben insertarse de forma permanente en la Base de Datos y mostrarse visualmente en una JTable.
 • Módulo EXTRA ALEJANDRO (Conexion remota): Conexion remota en tiempo real a la Base de datos desde cualquier dispositivo a travez de una integracion con AWS o con algun servico web de nulo costo.

 Subiremos los cambios actualizados cada que sea posible al repositorio
 Los comentarios estan permitidos para mejor depuracion
 El historial del repositorio estara actualizado con los cambios de cada uno como demostracion del trabajo en grupo que exigio el ingeniero
 Subir sus cambios y archivos como BORRADORES a una carpeta con el nombre del modulo de cada uno  (ex. "Modulo 1") para que podamos juntarlos al final y compilarlo en una sola maquina
 Una vez los 3 modulos de cada uno esten realizados, ALejandro unira todos las partes para volverlas parte de una sola JVM y que pueda compilarse en cualquier otro dispositivo.
